# 亮点 · 功能说明

把 B站 / 小红书的推荐流，变成你自己的样子。

亮点是一个安卓小工具。你照常刷，它把「不想看」的封面盖灰，把「特别关注」的封面点亮；
也可以在亮点里直接看 B站 推荐和关注，收藏想留的内容。亮点本身不用注册账号，
装好后填一次 B站 Cookie 和 DeepSeek Key 就能用。

## 三个效果

| 封面上的样子 | 意思 |
|---|---|
| 灰色半透明 | 这条大概率不想看 |
| 暖橙色光 | 这条是特别关注的 |
| 没变化 | 普通，或者还没判出来 |

## 功能一览

### 刷 B站

- **推荐流**：亮点自己拉一份 B站 推荐，按你的偏好判断。判为「不想看」的直接不显示，
  判为「特别关注」的带光。
- **关注流**：关注 UP 主的最新投稿逐条出现；同一位 UP 的多条投稿都会保留。
- **原生 App 封面标记**：从亮点入口打开 B站，首页封面会盖灰 / 发光；
  视频详情页往下滑的「相关推荐」也会标。
- **刷新与续翻**：首页下拉更新；关注流底部可以「加载更早的更新」。

### 刷小红书

- **小红书入口**：从亮点打开小红书，首页封面会按同一套偏好盖灰 / 发光。
- 目前只适配首页，详情页不标记。

### 找内容

- **搜索入口**：在亮点，点搜索，直接跳到 B站 / 小红书的搜索页；
  在平台里屏幕边有「返回亮点」气泡。
- **收藏**：B站 视频、小红书笔记都能收藏（笔记用链接收藏）；支持多收藏夹、置顶、排序、按标题搜收藏。
- **复制链接收藏**：在外面复制 B站 / 小红书链接，切回亮点会自动弹出预览，确认就能存。

### 让它更懂你

- **判断偏好**：填「特别关注」「不想看到」，一键生成判断规则；
  规则可以自己改、恢复上次、清空。
- **样式**：发亮可以开关、调强度；灰罩可以开关、调不透明度。
- **一套偏好通用**：B站 推荐、关注、原生 App、小红书 共用同一套偏好。

### 用起来不费劲

- **入口自检**：从首页入口进入时，自动检查 App、无障碍、Key、规则四项；
  缺哪项直接告诉你去哪补。
- **返回亮点气泡**：在 B站 / 小红书里屏幕左边有橙色气泡，点一下回亮点。
- **自动停止**：回到亮点、回桌面、锁屏或切到别的 App，标记会自动停；
  下次从入口再进。
- **亮点不用登录**：没有账号、没有密码，装好就能用。

## 适合谁

- 经常刷 B站 / 小红书，但不想被纯娱乐内容占满的人
- 有明确「特别关注」方向的人（考研、编程、健身、做饭……）
- 愿意为 AI 判断充 10 元 DeepSeek 余额的人

## 不适合谁

- **期待 100% 准确的人**：判断只看标题和作者，会误判；拿不准时保留为普通。
- **用 iPhone 的人**：目前只有安卓版。

## 怎么开始

1. 装 APK（Android 8.0 以上）
2. 填 B站 Cookie 和 DeepSeek Key（DeepSeek 充 10 元能用很久）
3. 开无障碍（不同手机位置不一样，找不到就搜「无障碍」）

详细步骤、截图和常见问题见 [使用说明](liangdian-getting-started.md)。
