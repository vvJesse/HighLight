# 亮点 · 常见问题与限制

主说明在 [使用说明](liangdian-getting-started.md)。

## 配置

**Q：Cookie 过期了怎么办？**

Cookie 一般能维持几个月。改密码、退出登录、或隔了很长时间，都可能让它失效。
亮点提示「B站 凭据已失效，需要更新」时，按主说明第 3 步重新取一次，粘贴保存即可，不用动 Key。

**Q：整段 Cookie 不好复制，只复制 SESSDATA 行吗？**

可以：

1. 开发者工具顶部点「**Application**」（应用）。
2. 左侧 Storage → **Cookies** → `https://www.bilibili.com`。
3. 找到 **`SESSDATA`**，双击 Value，复制。
4. 在亮点里只粘贴这个值，App 会自动补上 `SESSDATA=`。

推荐还是用整段 Cookie，成功率更高。

**Q：找不到 `web?` 请求，或者提示 Provisional headers？**

- 点一下 Filter 里的「Fetch/XHR」，再刷新页面；
- 或者按 F5 后再点列表最上面的 `web?`；
- 提示「Provisional headers are shown」时，刷新后重新点一次请求。

**Q：入口检查显示「还差 1 项」？**

看是哪一项：

- 没装 B站 → 去应用商店安装；
- 无障碍没连 → 重新开「亮点 · 封面标记」；
- Key 无效 → 检查 Key 有没有复制完整、DeepSeek 有没有余额；
- 判断规则为空不用管，会自动使用默认规则。

**Q：无障碍开了，1–3 秒又自己关了？**

这是系统在拦截，不同手机的处理位置不一样。先试「设置 → 应用 → 亮点」里的
「自启动」「后台运行」「电池优化」，允许它后台活动。

如果还不行，按品牌找：

- **OPPO / 一加 / realme**：手机管家 → 实用工具 → 风险行为拦截 → 右上「更多选项」→
  拦截白名单 → 添加「亮点」。
- **小米 / 华为 / 其他**：设置里搜「自启动」「后台运行」「电池优化」，允许亮点。

找不到就搜关键词，不同系统路径不一样，多试两步。

**Q：卸载重装后要重新弄吗？**

要。白名单条目可能丢失，需要重新加一次；配置和收藏也会清空。

## 使用

**Q：从入口进去了，但封面没有灰罩 / 光？**

按顺序检查：

1. 是不是从亮点入口（或亮点里的卡片 / 搜索 / 收藏）打开的？直接开 B站 不算；
2. 设置 → 检查与引导，四项是不是都通过；
3. 当前内容是不是真的命中了「不想看 / 特别关注」；
4. 新卡第一次要等模型返回，大约 1 秒；连续快滑时会更慢；
5. 小红书只有首页会标记，详情页不标。

**Q：为什么有的卡标记慢？**

原生 App 里是看到哪张判哪张，新卡通常等 1 秒左右；亮点自己的列表一次刷新会判一批，
100 条大约 10 秒。识别不到封面、直播卡、半露卡也可能不画。

**Q：B站 提示「凭据已失效」？**

Cookie 过期了。重新取一次，粘贴保存，不用动 Key。

**Q：Key 提示无效 / 余额不足？**

去 platform.deepseek.com 看「用量信息」。没余额就再充 10 元；
Key 被删了就重新建一个，填回亮点。

**Q：两台手机能共用一个 Key 吗？**

可以，余额共用；但 B站 Cookie 要各填各的，因为那是各自的登录状态。

**Q：换手机或卸载会怎样？**

配置、收藏、判断缓存都在本机，不会跟过去。换手机要重新填 Cookie 和 Key。
卸载前如果想留收藏，先自己记下链接。

**Q：会不会把我看的内容上传？**

亮点只把**标题、UP 主名字**和你填的偏好发给 DeepSeek，用来判断；
不会发 Cookie、Key、视频内容、评论或聊天记录。App 没有账号系统，也没有云同步。

## 已知限制

| 限制 | 说明 |
|---|---|
| 判断靠标题和 UP 主 | 不是看视频内容，会误判；拿不准时保留为普通 |
| 小红书只适配首页 | 详情页、半露卡、GIF/直播卡可能识别不到 |
| B站 不是所有页面都标 | 首页推荐、视频详情页的「相关推荐」已适配；其他页面不一定 |
| Cookie 会过期 | 过期后重新取一次，其他配置不用动 |
| 只在本机 | 换手机/卸载会丢配置、收藏和判断缓存，没有云同步 |
| 新卡要等一次模型 | 原生 App 里新卡约 1 秒；亮点列表整批约 10 秒（100 条） |
| 当前是内部试用版 | 安装包只发给可信的人，不要公开分发 |

## 隐私与安全

- **B站 Cookie** 和 **DeepSeek Key** 用 Android Keystore 加密后只存在这台手机，
  不写入 APK、源码或普通日志。
- AI 请求由手机直接发往 DeepSeek，只带标题、作者和你的偏好，不带 Cookie/Key。
- 亮点没有账号、没有登录、没有云同步，也不连接开发者的服务器。
- **Cookie 等于你的 B站 登录状态，Key 等于你的 DeepSeek 钱包。**
  不要发群里、不要截图露出来；发给文件传输助手后，记得删掉那条消息。
- 手机要送人/卖掉之前，先在系统设置里清除亮点数据或卸载。
