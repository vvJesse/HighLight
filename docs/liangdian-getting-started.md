# 亮点 · 使用说明

> 刷 B站 / 小红书时，把「不想看」的封面盖灰，把「特别关注」的封面点亮。
> 照着下面 5 步做，大约 20 分钟。

| 封面上的样子 | 意思 |
|---|---|
| 灰色半透明 | 不想看 |
| 暖橙色光 | 特别关注 |
| 没变化 | 普通，或者还没判出来 |

## 开始前

一台安卓手机（8.0 以上）、一台电脑、10 元、亮点 0.6 安装包。
手机上装好并登录 B站 / 小红书。

## 1. 装亮点

1. 把 APK 发到手机，点开安装；允许「安装未知应用」。
2. 如果提示「安装增强防护 / 安全检测」→ 继续安装。
3. 第一次打开允许通知。

## 2. 充 10 元，建 DeepSeek Key

1. 电脑或手机打开 **https://platform.deepseek.com/api_keys**，注册 / 登录。
2. 左侧「**充值**」→ 充 **10 元**。
3. 左侧「**API keys**」→ 右上「**创建 API key**」→ 名字随便填。
4. 弹出一串 **`sk-` 开头**的字符：**先复制，再关窗口**。关了就看不到了。
5. 先存到备忘录，或发给微信「文件传输助手」（**别发群里**）。


## 3. 取 B站 Cookie

1. 电脑 Chrome 打开 `bilibili.com`，确认右上角已登录。
2. 按 **F12** → 点「**Network**」→ 按 **F5** 刷新。
3. 点一个 **`web?`** 开头的请求 → 右侧「**Headers**」→「**Request Headers**」→ **`Cookie`**。
4. 右键 Cookie →「**Copy value**」（不是 Copy）。
5. 发到手机的文件传输助手；**Cookie 等于登录状态，别发给别人；用完删掉这条消息**。


> Cookie 过期、只复制 SESSDATA、找不到 `web?` 请求：见 [常见问题](liangdian-faq.md)。

## 4. 填进亮点，开无障碍

1. 打开亮点 → 右上角**齿轮**。
2. 第一次会弹「**先把这三步走完**」→「**开始配置**」。
3. **01 粘贴凭据**：粘 Cookie → 保存。
4. **02 连接 AI**：粘 Key → 保存 → **测试连接**，看到「测试通过」。
5. **03 开启服务**：点「**去系统设置**」→ 在无障碍里找到「**亮点 · 封面标记**」并打开。
   不同手机的位置和叫法不一样，找不到就在设置里搜「无障碍」。
6. 回亮点点「**完成**」。

> 如果无障碍开了又自己关掉，是系统在拦截。不同品牌处理方式不一样，见 [常见问题](liangdian-faq.md)。

## 5. 开始用

1. 首页顶部选「**B站**」→「**推荐**」→ 点「**B站 · 亮点**」入口卡。
2. 四项自动检查，通过后自动打开 B站。
3. 封面：灰 = 不想看，暖光 = 特别关注。
4. 屏幕左边橙色气泡「← 返回亮点」点一下回来；离开 B站 约 5 秒后自动停止。
5. 小红书：首页切「**小红书**」→ 点「**小红书 · 亮点**」入口卡。
6. 亮点首页的「推荐 / 关注」列表也能直接看；判为不想看的直接不显示。

> 只有从亮点里打开才会标记；直接从桌面开 B站 / 小红书不算。

## 10 元能用多久

按 10 万张新卡算：

| 每天新卡 | 10 元大约 |
|---|---|
| 200 张 | 1 年 4 个月 |
| 500 张 | 6 个半月 |
| 1000 张 | 3 个半月 |

*看到 500 张这一行，其实已经不用太算 10 元能用多久了：都刷到这个量，亮点大概也没帮你省下什么注意力。真到这一步，它最该给你的建议可能是——别续费了，先歇会儿。*

重复的卡不扣钱。完整算法和其他情况见 [10 元能用多久](liangdian-cost.md)。
